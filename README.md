# Kohorts (MVP v1.1)

Kohorts is a lightweight platform that helps cohort-based founders
automate enrollment and community access without handling payments.

## What Kohorts does

- Hosts public cohort pages
- Redirects students to founder-owned Paystack payment links
- Verifies successful payments via webhooks
- Automatically enrolls students
- Sends community access links (Discord, Slack, Telegram)

## What Kohorts does NOT do

- Does not process payments
- Does not hold funds
- Does not split revenue
- Does not act as escrow
